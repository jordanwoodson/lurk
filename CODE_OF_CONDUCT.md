# Code of conduct

This project is maintained in spare time and used by people who just want their streaming
apps to leave them alone. Keep it pleasant.

**Expected**

- Be kind and assume good faith. Most issues come from a missing detail, not from malice.
- Keep discussions on the project. Which streaming service or streamer is better is for
  somewhere else.
- Give others room: nobody owes anyone a fix on a deadline, including the maintainer.
- Respect what the rules protect: original work, honest patch descriptions and users' privacy.

**Not accepted**

- Insults, harassment, discrimination or sexualized language, in issues, pull requests,
  commits or anywhere else connected to the project.
- Publishing someone's private information.
- Deliberately misleading reports, or pushing for features that would harm users (hidden
  data collection, for example).

**Enforcement**

The maintainer may edit, hide or lock contributions that break this, and block repeat
offenders. To report something, contact the maintainer through GitHub: open an issue, or use
the private form under Security › Report a vulnerability if it shouldn't be public. Reports
are handled in confidence.
